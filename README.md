# AlgoMotion

**让思路，动起来。** 本地优先的算法可视化实验室：修改输入、查看结果，逐步观察算法为什么这样运行。

React + TypeScript + Vite / Express / Zod / Python / Docker

AlgoMotion 面向桌面浏览器，不是需要安装的桌面客户端，也不是双击即可运行的 HTML 文件。动画根据执行快照回放，而不是预录视频。

## 两种使用方式

| | 预设题演示 | AI 生成新题演示 |
| --- | --- | --- |
| 适合 | 直接学习已有算法 | 输入题库之外的题目，生成可执行演示 |
| 执行来源 | 浏览器内受信任的 TypeScript 执行器 | 模型生成 Python，在受限容器中执行 |
| 代码展示 | Java、Go、Python 参考实现 | 实际执行的 Python 源码 |
| 额外依赖 | 无需模型、Docker 或语言编译器 | 自备模型 API 和 Docker 兼容 Linux 引擎 |
| 修改输入 | 本地重新计算 | 复用 Python 与展示设计，不再次调用模型 |

开放生成不限于预设题名，但**不承诺正确解决任意算法题**。结构合法、运行成功、样例通过和独立验证是不同证据；模型自己生成的样例不算独立验证。

## 功能

- 播放、暂停、单步前进/后退、时间轴和变速，代码高亮与当前快照同步。
- 数组、双指针、链表、树、网格、队列、路径与 DP 依赖等可视化，保留交换、入队、重连和状态转移的因果动画。
- 自定义 JSON 输入、当前执行结果、轨迹导出；生成结果支持保存、导入和重跑。
- “生成新题演示”独立窗口：解析题意、审核默认约定、生成、执行、检查，然后在主界面回放。
- 可选 AI 定制展示：模型组合受控 React/SVG 组件，不执行模型生成的 HTML、JavaScript 或 CSS。
- 多套具名 API 配置，支持 DeepSeek、Kimi/Moonshot、OpenAI 和自定义 Chat Completions 兼容接口。
- “我的题库”保存草稿与演示，支持自选分类、搜索、编辑、导入和导出。

## 快速开始

安装 [Node.js](https://nodejs.org/en/download) **22.12 或更高版本**，建议使用受支持的 LTS 版本，npm 随 Node 一起安装。

在 **与本 README 同级、包含 `package.json` 的应用目录**打开终端。若拿到的是外层工作目录，先进入 `outputs/algomotion/`；若拿到的是应用源码压缩包，解压后直接进入包含 `package.json` 的目录。不要在用户主目录运行这些命令。

```sh
npm ci
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)，在左侧题库选择预设题。终端保持运行，按 `Ctrl+C` 停止。缺少容器时的生成模式警告不影响预设题。

首次下载依赖需要网络，之后预设题可离线使用；字体随依赖打包。不要跨系统复制 `node_modules`。

### 启用 AI 生成

macOS 已安装 Node.js 和 [Homebrew](https://brew.sh/) 时，可在应用目录执行：

```sh
npm run setup -- --install-docker
npm run dev
```

该命令按需安装 Colima + Docker CLI、准备后台容器环境、安装项目依赖并构建沙箱镜像，**不会安装或打开 Docker Desktop**。已有可用引擎可以复用；不自动购买、配置或调用模型 API。

在网页右上角“模型设置”中新增自己的配置，填写供应商、Base URL、模型名和 API Key，保存并使用。再点击“生成新题演示”。Windows 推荐 WSL2 + Docker Engine，Linux 使用 Docker Engine，具体步骤见[安装指南](docs/INSTALL.md)。当前不是所有系统都能一条命令完成首次安装。

模型配置默认明文保存在本机 `.algomotion/model-settings.json`，重启后可复用；请勿分享该目录。持久保存不代表密钥永不过期。密钥不会写入浏览器持久存储或导出的轨迹包。

## 开发与构建

```sh
npm run check
npm run build
npm start
```

构建后访问 [http://127.0.0.1:3001](http://127.0.0.1:3001)。此方式由 Node 服务提供网页与 API，仍是本地运行，**不是公网部署方案**。不要只拷贝 `dist/` 后期待生成接口可用。

`check` 包含类型检查和单元/API 测试，不调用付费模型。真实容器和模型测试另行显式运行，见[贡献指南](CONTRIBUTING.md)。历史测试结果不替代新机器上的实际验收；Colima 全新安装、Windows/WSL2 和 Linux 首次环境配置仍需独立实测。

## 安全与限制

- 生成 Python 只在受限 Linux 容器运行：禁网、非 root、只读根文件系统，无用户目录、密钥或 Docker socket 挂载，并限制 CPU、内存、进程、时间及输出。缺少环境时明确失败，不回退到宿主机 Python。
- 本地 API 具有容器引擎访问权限，默认只监听 `127.0.0.1`。普通 Docker 隔离不是公网多租户安全方案；不要把当前 API 暴露到公网。
- 生成和修复会将题目、必要输入、代码或采样轨迹发送给选定模型服务，并可能收费。不要输入公司内部资料、客户数据或其他无权外传的内容。
- 当前独立验证器只覆盖约定一致的四邻接障碍网格最短路和仅右/下的非负网格最小路径和，其他题会明确显示未独立验证。
- 个人题库仅存于当前浏览器来源，清理网站数据可能丢失，不会自动跨设备同步。请定期导出并审查备份内容。
