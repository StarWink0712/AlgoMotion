# 使用手册

[返回 README](../README.md) · [安装指南](INSTALL.md) · [故障排查](TROUBLESHOOTING.md)

## 预设题：输入、输出与播放

1. 从左侧题库选择题目，可按题名、题号或分类查找；无需另一个“打开预设题”入口。
2. 按输入提示编辑 JSON 并运行。输入校验失败时保留上次成功轨迹，不把错误输入当成执行成功。
3. 输入旁的输出区显示这次执行的最终结果，不用等待动画结束；未执行的输入修改或非法输入会明确标记保留的是上次结果。
4. 用播放/暂停、单步前进/后退、时间轴和速度观察状态。拖动时间轴读取对应快照，不倒着执行算法。
5. 代码下方查看“算法关键”；语言兼容说明可展开。Java/Go/Python 是参考实现，切换不改变当前结果或播放位置。

普通预设在浏览器内执行受信任 TypeScript，不要求 Java/Go/Python 环境，不支持把任意代码粘贴进编辑器运行。预设轨迹可导出供检查，**预设 Trace v1/v2 暂不支持导入**；不要与生成结果包导入混淆。

系统开启“减少动态效果”时，保留状态和关系图但减少过渡。长输入在画布内滚动；输入规模按教学可读性限制，不等同于在线评测平台的最大约束。

## 生成一道新题

生成前需就绪的模型配置、容器引擎和沙箱镜像，见[安装指南](INSTALL.md)。不要提交敏感题面或业务数据。

1. 点击“生成新题演示”打开独立窗口，输入目标、输入输出要求和特殊规则。
2. 请求解析后，核对结构化约定和“默认约定与关键假设”。模型自行选择常规实现方式，不要求逐项确认快排基准、分区等细节；缺失关键目标、冲突要求或无法推断的规则仍会追问。
3. 有误时修改题目重新解析，或编辑并应用约定 JSON。回答真正未解决的问题后再次确认；不支持的表达不会强行套进预设题。
4. 仅在题意与验证器规则完全一致时选择独立验证器，其他题选择“无独立验证器”。选择是否启用“AI 定制展示”，确认提交。
5. 服务端接受任务后，窗口关闭，主界面展示生成 Python、执行、检查、设计展示及完成/失败的真实阶段，不是假进度。
6. 完成后查看实际 Python、返回值、证据和回放；可切换原始轨迹，检查网格、队列、访问标记、候选依赖及路径重建过程。

关闭窗口或按 Escape **不会取消**已开始的解析或生成。主界面的“编辑题目与约定”可重新打开，运行中只读；取消需明确点击“取消任务”。未保存表单只保留在当前页面，刷新或离开页面不保证保留。API 重启会丢失临时任务，长期保留请保存演示或导出。

AI 定制展示返回 SceneSpec 数据，由受控 React/SVG 组件渲染，不是模型 HTML/JS/CSS。主画布标题和摘要从当前快照推导；AI 原始文案在明确标注为静态、可能剧透的查看区提供。模型对算法与状态的解释仍可能出错。

### 可尝试的题意示例

下面只是手动验收输入，不是生成器内的题名特判，也不保证某个模型一次生成成功。

**带障碍网格最短路径：** 给定矩形 0/1 网格，0 可通行、1 为障碍，坐标从 0 开始。输入 `grid`、`start`、`end`，每步只能上下左右移动且费用为 1，返回最短步数和一条最短路径。无解返回距离 -1、空路径；可通行起终点重合时距离为 0、路径只含该点。展示 BFS 队列、访问过程和实际路径重建。

**网格最小路径和：** 给定非负矩形数值网格 `grid`，从左上到右下，每步仅向右或向下，路径和包含起终点。返回最小路径和与一条最优路径，展示 DP 候选来源、选择与实际路径重建。

具体字段、范围及异常输入约定仍须与解析结果核对。最优路径可能不唯一，不能因为路径与某个示例不同就判错。

## 读懂验证结果

| 标记 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 结构合法 | 数据满足当前协议、类型、引用和容量约束 | 题意被正确理解、算法正确 |
| 运行成功 | 程序在受限容器中完成并返回合法轨迹 | 返回值符合题目要求 |
| 模型样例通过 | 输出符合模型给出的样例声明 | 独立正确性证据 |
| 独立验证通过 | 适用参考实现检查了已执行测试的数值、路径合法性及最优性 | 任意题或全部输入上的正确性证明 |
| 教学轨迹检查 | 选定网格语义的有限过程规则通过 | 每一步解释都完整、可信 |
| 展示绑定检查 | 已执行输入的所有快照满足数据来源、引用、类型及布局容量限制 | 展示一定美观，或未执行输入也必定适配 |
| 文件声明，未重验 | 保存/导入包中声明了旧的验证结果 | 本次环境重新执行通过 |

当前独立验证器只覆盖四邻接 0/1 障碍网格最短路、仅右/下的非负网格最小路径和，详见[生成协议](GENERATION.md)。它们是检查器，不提供固定生成解法。其他题显示“独立验证未进行”。轨迹记录来自实际 Python 调用，但插桩代码仍不可信，不能把运行来源当成防篡改证明。

## 修改输入、重试与费用

| 操作 | 是否调用模型 | 行为 |
| --- | --- | --- |
| 解析题意/重新解析 | 是 | 生成输入输出约定和假设 |
| 首次确认生成 | 是 | 生成 Python，通过执行与检查后可再请求展示设计 |
| 复用程序重新执行 | 否 | 使用已有 Python 与设计，只重新执行/检查 |
| 修复程序并重试 | 是 | 生成新 Python 并重新执行/检查/设计 |
| 重新设计展示 | 是 | 保留 Python，重新执行/检查并请求展示设计 |
| 保存、导入、打开题库条目 | 否 | 仅存储或回放，不执行 Python |
| 保存或切换模型配置 | 否 | 仅改变后续任务配置 |
| 测试模型连接 | 是 | 明确同意后发送简短 JSON 请求 |

正常完整流程通常各请求一次解析、Python 和展示设计，关闭 AI 定制展示可省去设计请求。修复/重新设计也可能重新执行多个检查用例。没有自动付费重试；任何“通过”都按实际证据显示。

修改输入无需当前模型配置，但仍需容器。新输入超过已生成设计的容量时会明确失败，不能继续展示错位布局。失败时查看阶段、错误码和安全诊断；必要时显式修复或重新设计。不要把诊断源码、导出包或截图不加检查地公开。

## 模型配置管理

“模型设置”默认打开配置列表。选择“使用此配置”切换；“新增配置”创建；“修改”进入编辑。编辑某套配置不需要先激活它，“保存并使用”才保存并切换；取消编辑不保存。

- 最多保存 20 套具名配置，支持同一供应商的不同模型/账号；任务提交后保留自己的配置快照，不会中途切换供应商。
- 已有配置中，供应商与地址不变时，密钥框留空可复用这套配置自己的密钥；新增配置或更换地址/供应商需要填写对应密钥。
- 默认保存到本机明文文件 `.algomotion/model-settings.json`，重启后恢复。读接口不返回密钥，浏览器不持久化密钥，但本地文件仍需保护。
- “临时使用”只覆盖当前服务，不删除已保存配置；重启后恢复上次持久选择。`ALGOMOTION_SETTINGS_MODE=memory` 可禁用文件读写。
- “使用环境变量”保留所有配置，回到 `.env`；删除当前配置也回到环境变量，不自动选择另一家付费供应商。
- 多标签页共享同一 API 配置。遇到旧版本冲突，先“刷新配置”再操作；不要直接覆盖服务正在使用的配置文件。

配置持久化不等于密钥永不过期，也不等于连接已测试。供应商撤销密钥、欠费或接口变化时仍需更新。Kimi/OpenAI/自定义适配的协议测试不等于每个厂商、每个模型都已真实验证。

## 我的题库与备份

**保存草稿：** 在新题窗口输入题意，选择“保存题目草稿”，只保存题目文字，不保存未确认约定、不调用模型。重新打开后可继续编辑解析；生成演示不会自动覆盖草稿。

**保存演示：** 生成成功或导入合法结果包后，点击“保存到我的题库”。保存最后实际执行的输入、Python、快照、证据声明与可选设计，不保存尚未执行的输入框修改。

**管理：** 可编辑标题、选择 1–6 个分类，或创建自定义分类；支持搜索、重分类、另存副本、确认后删除。同名条目可共存。保存已打开条目会更新它；其他标签页已修改/删除时拒绝覆盖，需重新打开或另存。

**存储：** IndexedDB 最多 100 条 / 32 MiB，另受浏览器配额限制。仅属于当前浏览器来源，`localhost`、`127.0.0.1`、不同端口或浏览器之间不共享。清理网站数据、无痕会话结束可能丢失，源码备份不包含题库。

**导出/导入：** 题库卡片导出的 `algomotion-library-entry` v1 包含标题、分类和草稿/演示，使用“导入题库条目”检查并确认后保存为新条目，不覆盖同 ID 旧条目。普通 `algomotion-generated` v1/v2 结果包通过生成区导入后，再手动保存到题库。

重新打开演示只回放，不执行代码、不调用模型，旧证据标为未重验；明确点击“复用程序重新执行”后才有新证据。旧版单条“快速保存/重新打开已保存结果”仍是独立本地槽位，不自动迁移或覆盖题库。题库不是账户或云同步系统，也不保存 API Key。
